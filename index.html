⚙️ AI settings & API key

Robin uses an external AI service for free-text answers. The API key is a private credential from the selected provider — it is not your ChatGPT password or subscription. Each person must use their own provider key. Never share it, paste another person’s key, commit it to GitHub, or enter it on a shared/public device. IMPORTANT: this prototype stores the key in this browser profile’s localStorage and sends it from the browser to the provider. Browser storage is not a secure vault; scripts, extensions or anyone with access to this browser profile may be able to access it. Do not use a valuable or production key here. A public production app should send requests through a protected server-side backend instead. The Tonight, Weather, Depots and History dashboards work without a key; only Robin’s AI answers need one.

Get a free Gemini key: open Google AI Studio, sign in, click Create API key, copy your own key, paste it above and press Save. The key is stored in this browser only and is not written into this page’s GitHub source code. Check the provider’s current usage limits and pricing.

About the prices: Input means the text sent to the AI; output means the AI reply. Providers charge per token. These optional prices are only used to estimate the cost of a chat; they do not set or control the provider's actual charges. Leave them blank if you do not know the rates.
